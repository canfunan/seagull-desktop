# 海鸥桌面 逆向分析结论

> 目标：`cn.wayecai.launcher` v1.7.3（versionCode 38）
> 分析材料见 `reference/original-yecai/`

---

## 一、基本信息

| 项 | 值 |
|---|---|
| 包名 | `cn.wayecai.launcher` |
| 版本 | 1.7.3 (38) |
| APK 大小 | 533 KB |
| 业务代码 | 9 个类 / 3340 行（反编译后） |
| UI 文案 | 1173 条中文 |
| 签名 | 泄漏的 AOSP testkey（SHA-256 `c8a2e9bc…92ab8`） |
| 关键声明 | `android:sharedUserId="android.uid.system"` |

### 为什么装不上

原版声明了 `android:sharedUserId="android.uid.system"`，但用的是泄漏的 AOSP 测试签名。
系统要求 sharedUserId 为 `android.uid.system` 的应用必须由**平台密钥**签名，且签名链条一致。
安装直接报：

```
INSTALL_FAILED_SHARED_USER_INCOMPATIBLE: ... signing lineage that diverges
```

**这不是可以绕过的配置问题，而是签名链条校验。** 想装原版只有两条路：
装到 `/system/priv-app` 并用平台密钥重签（需要解锁 BL + 改系统），或者改包名去掉 sharedUserId（等于重做一个）。

这也解释了为什么它要有 `platform` 版本 —— 那个版本是给车机厂商预装的。

## 五、特色功能

### 菜园
> 长按叶子 → 进菜园（大时钟 + 歌词，再长按退出）

- 进菜园后画中画窗口藏起来（应用继续后台跑，回来秒开）
- 只留壁纸和几行字
- 按主页键、返回键也会回去
- 菜园里点叶子出的是应用列表
- 遮罩与「外观」里的遮罩分开，浅色主题下从白雾换成黑色

### 小白点
> 浮在屏幕上的小圆点，用别的应用时点一下就回海鸥桌面

- 拖到哪就停在哪；打开后松手会自动贴到最近的左右边
- 位置记在本机、不进云端存档
- Dock 关着时小白点变成悬浮键：默认在左下角，按住能拖到任何位置

### 海鸥岛
> 屏幕顶部的胶囊。状态栏隐藏时它会浮在窗口上面

- 距顶部偏移（应对挖孔/圆角/固定状态条）
- 宽度可调，歌词太长会撑宽挡住窗口顶部

## 六、窗口能力分档（原始定义）

```
L0 启动卡片（无窗口权限）
L3 虚拟屏窗口
```

原文案说明：
> 画中画开几个只给建议、不做限制，想开满还是你说了算
> 海鸥会按本机硬件自动定档。低配机上少做几件费显卡的事

性能档位：`低配 / 中配 / 高配`，预设示例：
- `4 个窗口，高配机器用`
- `三个窗口一样高，高配机器用`
- `四等分，接单用；高配机器`
- `低配` 建议不保留后台窗口

## 七、触摸子系统（原文案）

> 点、滑、长按窗口里的应用时，海鸥怎么把手指传进去。

设置项：
- 触摸方式
- 防误滑
- 长按判定（`按住 0.3 秒` / `按住 0.5 秒`）
- 跟手

原文案明确：
> 长按判定关闭时，按住不动也只算一次点按；打开后，按住超过设定时间会转成长按。
> 点了没反应、老被当成滑动时，把防误滑调强。

技术侧（来自参考仓库逆向）：
- `injectInputEvent` 不可用时会打印 `injectInputEvent 不可用: ...`
- 说明它有一条 `InputManager.injectInputEvent` 通道，但需要特权

## 八、歌词子系统（原文案）

优先级链：
```
播放器自带的整首歌词  →  本地 .lrc  →  在线歌词（酷狗）  →  播放器给的当前这句
```

> 整首歌词才能一屏多句。

三条通道：
| 通道 | 权限 |
|---|---|
| 车载蓝牙歌词（读媒体信息） | 不需要通知使用权 |
| 通知文字歌词 | 需要通知使用权 |
| 状态栏歌词 | 需要通知使用权 |

> 不少播放器只在检测到蓝牙已连接时才输出，本机连着车上的蓝牙最稳。

隐私说明（原文案）：
> 只把歌名、歌手、时长发给酷狗，不带账号和设备信息。每首歌只查一次，查到的存在本机，没网也能用。

## 十、原版反盗版机制（仅记录，不绕过）

原文案暴露出多层校验：

```
安装包不是原厂签名的，已丢弃
安装包不是官网那一份，会员不生效
安装包版本号对不上，已丢弃
安装包里的包名对不上，已丢弃
服务器报的包名对不上，已忽略
读不出安装包的签名，已丢弃
没有可比对的签名指纹，已丢弃
下载地址不在 update.wyctt.com 上，已拒绝
这一份安装包被停用了（通常是流出去的破解或二次打包版本）
```

**本项目不涉及也不实现任何绕过逻辑**，以上仅作为「原版有强完整性校验」的事实记录。

## 十一、代码量的启示

原版 533 KB / 9 个业务类 / 3340 行，却实现了 205 条功能。原因是：

1. **窗口管理完全委托给系统** —— 不自己画窗口，只调 `startActivity` / `DisplayManager`
2. **UI 高度复用** —— 一套自定义 View 渲染所有设置项（列表 + 开关 + 滑块）
3. **文案集中** —— 1173 条中文字符串，大量是状态提示而非独立功能

**结论：功能多不等于代码多。** 本项目不需要为了"对齐"而把代码量堆上去，
重点是每个功能点真正可用。
