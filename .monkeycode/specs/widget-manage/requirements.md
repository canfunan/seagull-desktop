# Requirements Document — 组件管理：负一屏卡片 + 壁纸页块（批次 Q）

Feature Name: widget-manage
Updated: 2026-10-19
前置：无（纯 UI/配置能力，不依赖真机特殊硬件）

## Introduction

负一屏五张卡（天气/快捷开关/限行/目的地/日志）目前写死两列、无任何长按交互；壁纸页六块已有拖动/隐藏/时钟菜单找回，但时钟块自身无法隐藏、块管理与小组件添加入口分散。本功能统一两页的组件管理能力：长按移动位置（负一屏=上移/下移重排）、长按删除（隐藏）、统一入口添加（找回）。

## Glossary

- **卡片 key**：负一屏卡片标识（weather/switches/restrict/dest/log）
- **卡片序**：负一屏卡片的展示顺序，奇数位进右列、偶数位进左列（默认序恰好还原现状布局）
- **隐藏**：卡片/块从页面收起但配置保留，可通过组件管理找回（区别于删除数据）
- **组件管理**：两页通用的组件显隐清单对话框，点行切换显隐
- **块**：壁纸页六个信息块（时钟/行车/倒数/监控/音乐/G值）

## Requirements

### R1 负一屏卡片重排

**User Story:** AS 车主，I want 长按任意卡片调整它在前屏的位置，so that 高频卡放最上面。

#### Acceptance Criteria

1. WHEN 长按任一卡片，系统 SHALL 弹出菜单：上移、下移、隐藏、组件管理。
2. WHEN 用户选上移/下移，系统 SHALL 把该卡在卡片序中与相邻卡交换位置并立即重排（首位上移/末位下移为无操作），配置持久化。
3. WHEN 重排发生，系统 SHALL 按新卡片序重新分配左右两列（偶数位左列、奇数位右列），卡内运行状态（开关 chip 颜色、天气文本）保持不变。
4. IF 用户从未改过卡片序，系统 SHALL 呈现默认序 weather、switches、restrict、dest、log，与改造前视觉布局完全一致。

### R2 负一屏卡片显隐

**User Story:** AS 车主，I want 隐藏用不上的卡、找回藏起来的卡，so that 前屏只留有用的东西。

#### Acceptance Criteria

1. WHEN 用户在卡片菜单选隐藏，系统 SHALL 把该卡从页面收起并持久化，剩余卡按序重排。
2. WHEN 长按负一屏空白区域，系统 SHALL 弹出组件管理对话框，列出全部五张卡及当前显隐状态，点行切换。
3. WHEN 全部卡片都被隐藏，负一屏 SHALL 保持空白背景可用，空白区长按仍可进入组件管理找回。
4. IF 配置档里出现未知卡片 key 或缺失的默认卡，加载时 SHALL 丢弃未知 key 并把缺失卡追加到序尾（前向兼容）。

### R3 壁纸页块管理

**User Story:** AS 车主，I want 壁纸页的块也能统一管理（含时钟块），so that 两个页面交互一致。

#### Acceptance Criteria

1. WHEN 长按壁纸页空白区域，系统 SHALL 先弹入口菜单：添加小组件、组件管理（原行为是直接进添加小组件）。
2. WHEN 进入组件管理，系统 SHALL 列出六个块（含时钟块）及显隐状态，点行切换；时钟块隐藏后仍可从此找回。
3. WHEN 时钟块菜单，系统 SHALL 保留原有找回被隐藏块的能力，并新增「组件管理」项与「隐藏时钟块」项。
4. IF 页面上所有块与小组件都被移除，壁纸页 SHALL 保持可操作：空白长按仍能进入组件管理/添加小组件。

### R4 持久化与健壮性

**User Story:** AS 用户，I want 调好的卡片布局重启后还在，so that 不用反复调。

#### Acceptance Criteria

1. WHEN 卡片序或显隐变化，系统 SHALL 全量写回配置档并在重启后恢复。
2. IF 配置读取出错，系统 SHALL 回落默认序与全显状态，页面正常渲染。
3. WHILE 换肤或重建页面，卡片 SHALL 按持久化序重建，运行态轮询（开关 2s tick）不受重排影响。
